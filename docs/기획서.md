## 3. 롤 시스템

### 3-1. 판정 방식
1. 현재 롤 가능한 오라 목록(일반 52 + 진행 중 이벤트 전용)을 **희귀한 순서**로 정렬.
2. 가장 희귀한 것부터 `min(1, 운 / 확률분모)` 확률로 판정 → 성공하면 그 오라 획득, 실패하면 다음 오라로.
3. 끝까지 실패하면 「먼지별」.
4. 난수는 `crypto.getRandomValues` 사용 (균등·예측 어려움).
5. 운이 매우 높으면 흔한 오라가 자연스럽게 덜 나오게 됨 (의도된 동작).

### 3-2. 운(Luck) 계산
```
최종 운 = (1 + 장비 운 + 환생 운 + 업적 운)
        × 포션 배율 × 이벤트 배율 × 별의 축복 배율
```
- 기본 운 1.0
- **별의 축복**: 롤 10회마다 1회 운 ×2 (환생 트리로 주기 단축·배율 강화). 축복 롤은 롤 버튼 테두리가 금색으로 빛나서 미리 알 수 있음.

### 3-3. 롤 속도
- 기본 롤 시간 1.2초 (슬롯 연출 포함) → `1.2 / 속도 배율`
- 최저 0.15초 제한.
- 롤 연출: 더미 아래 이름 슬롯이 빠르게 바뀌다가 감속 → 결과 확정.

### 3-4. 자동 롤 / 빠른 롤
- **자동 롤**: 누적 100회 롤 후 해금. 토글식.
- **빠른 롤**: 누적 1,000회 롤 후 해금. 슬롯 연출 생략, 롤 시간 ×0.6.
- **컷신 생략 기준**: 설정에서 "이 등급 이하 컷신 생략" 선택 (기본: 혜성 이하). **펄서 이상은 생략 불가** (스킵 버튼은 3초 뒤 표시).
- 자동 롤 중 희귀 오라(설정 기준 이상) 획득 시 자동 롤 일시정지 옵션.

### 3-5. 별가루 (재화)
- 롤마다 획득: `max(1, floor(log2(확률분모)))` (예: 1/1000 오라 → 9)
- 이벤트·업적·포션으로 배율 증가.
- 사용처: 상점 포션, 장비 제작, 일부 업적 보상.

## 4. 인벤토리 / 장착
- 오라별 보유 수량 저장 (중복 누적).
- 오라 1개 장착 → 더미에 표시. 장착은 무료·즉시.
- 정렬: 희귀도 / 획득순 / 보유량. 필터: 등급별.
- **분해**: 중복 오라를 별가루로 변환 (롤 획득량 ×3). 장착 중이거나 1개 남은 것은 분해 불가. 실수 방지를 위해 항성 이상은 확인창 표시.

| 운 포션 I | 운 ×1.5 | 3분 | 상점 200 별가루 |
| 운 포션 II | 운 ×2 | 5분 | 상점 1,500 |
| 운 포션 III | 운 ×3 | 5분 | 제작: 성운 등급 오라 3개 + 5,000 |
| 속도 포션 I | 속도 ×1.25 | 3분 | 상점 150 |
| 속도 포션 II | 속도 ×1.5 | 5분 | 상점 1,200 |
| 천체의 정수 | **다음 1회** 운 ×10 | 1회 | 제작: 항성 오라 1개 + 20,000 |
| 운명의 별 | **다음 1회** 운 ×100 | 1회 | 제작: 초신성 오라 1개 + 펄서 오라 1개 + 200,000 |

- 같은 종류 포션 재사용 시 **남은 시간에 더해짐** (최대 60분).
- 다른 종류끼리는 효과 곱연산. 운 포션 I~III은 **가장 높은 것 1개만 적용** (밸런스).
- 활성 효과는 화면 상단에 아이콘 + 남은 시간 원형 게이지로 표시.

## 6. 장비 제작

슬롯 2개: **장갑(운 중심)** / **목걸이(속도 중심)**. 상위 티어 제작 시 하위 티어 장비가 재료로 소모됨.

### 6-1. 장갑 계열

|------|------|------|------|
| T1 | 별빛 장갑 | 운 +0.1 | 먼지별 ×50, 새벽별 ×20, 500 |
| T2 | 혜성 장갑 | 운 +0.25, 속도 +5% | T1, 푸른 혜성꼬리 ×5, 소행성대 ×3, 2,000 |
| T3 | 성운 장갑 | 운 +0.5, 속도 +10% | T2, 장미 성운 ×2, 오리온의 숨결 ×1, 10,000 |
| T4 | 항성 장갑 | 운 +1.0, 속도 +15% | T3, 적색 거성 ×1, 북극성 ×1, 50,000 |
| T5 | 초신성 장갑 | 운 +2.0, 속도 +20%, 별의 축복 배율 ×2 → ×3 | T4, 초신성 잔해 ×1, 감마선 폭발 ×1, 250,000 |

### 6-2. 목걸이 계열
| 티어 | 이름 | 효과 | 재료 |
|------|------|------|------|

| T3 | 성운 목걸이 | 속도 +35%, 운 +0.1 | T2, 보랏빛 가스구름 ×2, 쌍둥이 별 ×1, 9,000 |
| T4 | 펄스 목걸이 | 속도 +50%, 운 +0.2 | T3, 백색 왜성 ×1, 쌍성계 왈츠 ×1, 45,000 |

## 7. 우주 이벤트 (날씨)

- 플레이 중 **5~10분 간격**으로 무작위 발생, 지속 **2~4분**. (오프라인 진행 없음)
- 이벤트 시작 3초 전 상단 경고 배너 + 효과음, 진행 중 남은 시간 표시.

| 이벤트 | 발생 비중 | 효과 | 배경 변화 |
|--------|-----------|------|-----------|
| 유성우 | 40% | 운 ×1.2, 별가루 ×1.5, 혜성 등급 확률 ×2 | 사선 유성이 계속 떨어짐 |
| 성운 폭풍 | 35% | 속도 ×1.3, 성운 등급 확률 ×3 | 보라·분홍 가스가 화면을 흐름 |
| 일식 | 20% | 운 ×1.5, 항성·펄서 등급 확률 ×1.5 | 화면이 어두워지고 상단에 일식 원반 |
| 행성 정렬 | 5% | 운 ×3 | 7개 행성이 일렬로 서서히 정렬, 금빛 띠 |

- "등급 확률 ×N"은 해당 등급 오라의 판정 분모를 N으로 나누는 방식.
- 이벤트 기록: 각 이벤트 경험 횟수가 도감·업적에 반영.

## 8. 도감 · 업적 · 환생

### 8-1. 도감
- 60칸 그리드 (등급별 섹션). 미획득은 `???` + 등급 색 테두리만, 확률은 `1/???`.
- 이벤트 오라 칸에는 이벤트 아이콘 표시 (힌트).
- 획득 칸 클릭 → 상세: 이름, 등급, 확률, 설명, **첫 획득 일시**, 총 획득 수, 더미 미리보기(실시간 렌더), 장착 버튼.
- 도감 완성률 % 표시, 등급별 완성 보상(별가루 + 칭호).
- 도감 기록은 **환생해도 유지**.

### 8-2. 업적 (30개)
| 분류 | 업적 예 | 보상 |
|------|---------|------|
| 롤 수 | 100 / 1,000 / 1만 / 10만 / 100만 회 | 별가루, 칭호 「별 헤는 자」 등 |
| 등급 첫 획득 | 각 등급 첫 획득 (9개) | 별가루, 2등급 이상은 칭호 |
| 도감 | 10 / 25 / 40 / 52 / 60종 | 운 +0.05 ~ +0.25 (영구) |
| 이벤트 | 각 이벤트 첫 경험, 이벤트 오라 8종 완성 | 별가루, 칭호 「천문학자」 |
| 제작 | 첫 장비, T5 장비 2종 완성 | 별가루 |
| 환생 | 1 / 5 / 10회 | 성핵 |
| 기타 | 축복 롤에 항성 이상 획득, 운명의 별 사용해서 꽝(먼지별) | 숨은 업적 (설명 숨김) |

- 칭호: 하나를 골라 더미 위 이름표에 표시 ("GRD · 별 헤는 자").

### 8-3. 환생
- **조건**: 이번 회차 총 롤 1만 회 이상 + 항성 등급 이상 오라 1개 이상 보유.
- **초기화**: 별가루, 인벤토리 오라, 장비, 포션, 롤 수(회차).
- **유지**: 도감, 업적, 칭호, 성핵 트리, 설정, 누적 통계.
- **보상**: 성핵 = `floor(sqrt(회차 롤 수 / 1000))` + 회차 최고 등급 보너스(항성 1 / 초신성 2 / 펄서 4 / 퀘이사 7 / 특이점 12 / 기원 25)
- **성핵 트리** (각 노드 레벨업식):
  | 노드 | 효과 | 최대 |
  |------|------|------|
  | 별의 은총 | 운 +5% / 레벨 | 10 |
  | 가속 궤도 | 속도 +5% / 레벨 | 10 |
  | 별가루 연금 | 별가루 +10% / 레벨 | 10 |
  | 축복 주기 | 축복 주기 10 → 9 → 8 → 7 → 6 | 4 |
  | 기억된 손 | 환생 시 장비 1티어 유지 | 1 |
  | 즉시 해금 | 자동·빠른 롤 처음부터 해금 | 1 |
  | 이벤트 자석 | 이벤트 간격 −10% / 레벨 | 3 |
- 환생 연출: 더미가 빛으로 흩어졌다 다시 모이는 3초 연출.

## 9. 디자인

### 9-1. 비주얼 톤

- 배경: 3겹 시차(패럴랙스) 별 레이어 + 아주 느린 성운 그라데이션 흐름.

- 머리 위 이름표: 칭호 + 장착 오라 이름(등급 색).

## 10. 획득 연출 (컷신)

| 등급 | 길이 | 연출 |
|------|------|------|
| 성진 | — | 하단 작은 토스트 |

## 11. 사운드 (Web Audio 합성, 외부 음원 없음)
- **롤 틱**: 짧은 사인파 블립, 슬롯 감속에 맞춰 음정이 내려감.
- **결과음**: 등급이 오를수록 화음이 풍부해짐 (단음 → 3화음 → 아르페지오 → 리버브 + 저음 서브).
- **컷신**: 라이저(상승음), 충격음(노이즈 버스트 + 저역), 특이점의 무음 구간, 기원의 오케스트라풍 패드.
- **BGM**: 느리게 변하는 앰비언트 패드(4화음 순환) + 필터링된 노이즈 바람. 이벤트마다 음색 변화.
- 볼륨: 마스터 / BGM / 효과음 슬라이더, 음소거 버튼. 첫 터치 후 오디오 시작 (브라우저 정책).

## 14. 성능 최적화
- 단일 메인 Canvas + 컷신용 오버레이 Canvas, `requestAnimationFrame` 루프 1개.

- 탭 비활성 시 렌더 중지 (자동 롤은 타이머 기반으로 계속 — 백그라운드 제한 고려해 경과 시간만큼 일괄 처리하되 최대 1분치).

## 15. 보안 · 배포
- F12 / Ctrl+Shift+I·J·C / Ctrl+U / 우클릭 / 텍스트 선택·드래그 차단, 개발자도구 열림 감지 시 화면 가림.
- JS 난독화 적용 (javascript-obfuscator). 원본은 `src/`에 보관.
- ※ 클라이언트 웹게임 특성상 완벽한 차단은 불가능하며, 분석을 어렵게 만드는 수준임.

### 파일 구조
```
/
├── index.html          ← 배포용 (난독화된 JS 참조)
├── assets/
│   ├── game.min.js     ← 난독화 결과물
│   └── style.css
├── src/                ← 원본 (유지보수용)
│   ├── data/auras.js   ← 오라·등급·이벤트·장비 데이터
│   ├── core/           ← 롤, 운 계산, 저장, 이벤트 스케줄러
│   ├── render/         ← 더미, 오라 렌더러, 파티클, 컷신
│   ├── audio/          ← Web Audio 합성
│   └── ui/             ← 패널, 모바일 시트, 토스트
├── build.sh            ← 번들 + 난독화 스크립트
└── docs/기획서.md
```
- 배포 주소: `https://0611gareddug.github.io/Sol-s-rng/` (저장소 이름 변경 시 함께 변경)
